Login with one-time code

The one-time code field carries autocomplete="one-time-code", which content/totp-field.js accepts unconditionally, and is also named otp, which is in its list of accepted names. Either alone is enough; both are set so a failure here means something other than detection.

Expect the code to match what Cipher shows for the same entry. It changes every 30 seconds, so compare them at the same moment.
