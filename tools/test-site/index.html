Cipher Bridge test site

Login forms for exercising the browser integration without depending on a real site. Submitting any of them shows exactly what was filled, so values can be checked rather than guessed at.

Forms

  • Simple login — username and password.
  • Login with one-time code — adds a field marked autocomplete="one-time-code", which the extension always treats as a TOTP field.
  • Two-step login — username first, password on a second view, as many real sites do. The hard case for field detection.
